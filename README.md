# 🎯 بازی تشخیص فیشینگ

یک بازی تعاملی و آموزشی برای یادگیری تشخیص پیام‌های فیشینگ (Phishing) در دنیای دیجیتال.

## 📋 درباره بازی

در این بازی ۱۰ سناریوی مختلف رو تجربه می‌کنی — از ایمیل‌های جعلی و پیامک‌های مشکوک تا تماس‌های تلفنی و تله‌های شبکه‌های اجتماعی. باید تصمیم بگیری که هر پیام امنه یا فیشینگ!

## 🚀 نحوه اجرا

فایل `phishing-game.html` رو توی مرورگر بازش کن:

1. فایل `phishing-game.html` رو پیدا کن
2. روش دابل‌کلیک کن یا در مرورگر بکش
3. دکمه **🚀 شروع بازی** رو بزن

هیچ نصب یا تنظیمی لازم نیست — فقط باز کن و بازی کن!

## 🛡️ نکات آموزشی

بازی به تو کمک می‌کنه پرچم‌های قرمز فیشینگ رو بشناسی:

- 🔍 آدرس ایمیل و دامنه رو چک کن
- ⏰ فوریت ساختگی رو بشناس
- 🔗 لینک‌ها رو قبل کلیک بررسی کن
- 📞 هیچ شرکتی رمز پویا تلفنی نمی‌خواد
- 🎁 جایزه بی‌دلیل = کلاهبرداری
- 💰 سود نجومی و تضمینی = پانزی

## 🛠️ تکنولوژی‌ها

- HTML5 + CSS3 + JavaScript (بدون وابستگی)
- فونت وزیرمتن (Google Fonts)
- طراحی RTL فارسی
- واکنش‌گرا (Responsive)
